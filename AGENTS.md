# Follo Cart backend

Laravel 13 / PHP 8.4 / MySQL 8.4. Use Docker Compose if PHP is unavailable locally.

- API routes live in routes/api.php; session-authenticated admin routes in routes/web.php.
- Public registration must never grant privileged roles. Authorize all owner and admin writes.
- Keep device tokens and Firebase credentials out of logs and API responses.
- Notifications are generated by notifications:dispatch; maintain deduplication and bounded retries.
- Run `docker compose exec -T app php artisan test` and `docker compose exec -T app vendor/bin/pint --test` after backend changes.
- Dashboard assets are plain Blade and public/admin.css; no frontend build is required.
- See doc/api.md and doc/system-design.md for contracts and deployment tradeoffs.
